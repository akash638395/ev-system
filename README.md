## 📌 Project Overview

The EV Charging Station Booking and Billing System is a Java-based application designed to manage electric vehicle charging station bookings and billing. It helps users book charging services and calculate the cost of charging.

## 🎯 Objectives

* Simplify EV charging station booking.
* Manage charging session details.
* Calculate charging costs automatically.
* Maintain booking and billing information.
* Demonstrate object-oriented programming concepts in Java.

## ✨ Features

* 🔋 EV charging session management
* 📅 Charging station booking
* 💰 Automatic bill calculation
* 🧾 Booking and billing details
* ☕ Java-based application
